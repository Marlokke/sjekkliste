# Sjekkliste – Løkkeberg Prosjekt AS

Enkel sjekkliste-app for å dokumentere arbeid underveis på prosjekter.

- Prosjekter med sjekklister basert på maler
- Status per punkt (OK / Avvik / Ikke relevant), kommentar og bilder
- Logg/dagbok med bilder
- Rapport som kan skrives ut eller lagres som PDF
- Sikkerhetskopi (eksport/import)

## Bruk

Åpne `index.html` i en nettleser, eller bruk GitHub Pages-adressen.

Data lagres lokalt i nettleseren på hver enhet (IndexedDB). Ta jevnlig sikkerhetskopi.
